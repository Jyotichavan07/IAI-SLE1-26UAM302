## 4. Issues / Risks Found

The project uses predefined rules, so its recommendations are limited to the conditions programmed into the agent.

One limitation identified is that the simple version does not perform advanced input validation for every possible incorrect input.

Other limitations include:

- The agent does not learn from previous user behavior.
- It does not use machine learning.
- It does not automatically update its rules.
- Its recommendations are limited to the predefined conditions.
- Different students may require different study strategies.

The code was tested with different input combinations to check whether the rules produced the expected recommendations.
